SQL Injection attacks are where SQL can be run on the website to find hidden data and bypass logins

Methods

  • Start by using a single quote in a login box, or in the URL itself to see if the site is susceptible to SQL Injection attacks:
    • '
    • If an internal Server Error error message is sent back, then there is a strong chance the site can be attacked with SQL injection

Bypassing Login Pages

  • Typically, the backend T-SQL would look similar to this: 
    • SELECT username FROM users WHERE firstname='administrator'
  • This won't work in the username box though, so try the below un the username box: 
    • administrator'--
    • Put anything in the password box since the above will make the backend not check for a password, bypassing it
  • Variations of "administrator" should be attempted to try and break in
